# Project Overview
This repository showcases a comprehensive journey through modern data management and database technologies, covering both traditional and AI-driven data architectures.

The project is organized into multiple parts, with each branch focusing on a key area:

Part1-RDBMS: Relational databases, SQL, Schema design, and data management.

Part2-NoSQL: Exploring flexible, non-relational database systems and use cases.

Part3-DataWarehouse: Data warehouse concepts, analytical workloads, and structured reporting.

Part4-VectorDB: Vector databases and their role in semantic search and AI applications.

Part5-DataLake: Handling large-scale, diverse, and unstructured data using data lake concepts.

Part6-Capstone: An integrated project applying the concepts learned across the different data technologies.

Datasets: Supporting datasets used throughout the projects and practical exercises.

Objective
The goal of this repository is to demonstrate practical understanding of databases, data engineering concepts, modern data architectures, and AI-ready data systems, progressing from traditional relational databases to advanced technologies such as Vector Databases and Data Lakes. From structured data to AI-ready data- exploring the evolving world of modern data systems.
